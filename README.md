# Noury Traveling & Tour Agency

Premium React + TypeScript + Vite website prepared for Vercel.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Vercel
Import this folder/repository into Vercel. Framework: Vite. Build command: `npm run build`. Output directory: `dist`.

### Important
This starter includes a polished public website and enquiry form. The form opens WhatsApp/email and does not pretend to be a secure backend booking database. For live production bookings/admin data, connect a real backend/database before collecting sensitive customer documents or payments.
